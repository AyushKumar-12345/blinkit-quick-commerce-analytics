# Blinkit Quick-Commerce Analytics and Operational Intelligence

## Executive Summary
An end-to-end data analytics and business intelligence project analyzing quick-commerce operations across 5,000 orders and INR 4.97M in Gross Merchandise Value (GMV).

This repository implements an automated Python ETL pipeline, an enterprise SQL analytical warehouse covering unit economics and SLA breach latencies, and an interactive web and Power BI intelligence suite designed to diagnose logistics bottlenecks, dark store efficiency, customer retention, and inventory shrinkage.

---

## Architecture and Data Pipeline
1. Inbound Datasets: 8 Relational CSV sources
2. Automated ETL (`process_blinkit_data.py`)
   - Text sanitization and duplicate pruning
   - Temporal standardization
   - SLA breach flag and delivery latency engineering
3. Relational Warehouse Queries (`blinkit_queries.sql`)
   - Star Schema design: 1 Fact, 7 Dimensions
   - Pareto 80/20 category revenue contribution
   - RFM customer segmentation via NTILE window functions
   - Month-over-Month growth and store efficiency ranking
4. Interactive Dashboard Applications
   - Live Web Application (`app.py`) built with Streamlit and Plotly
   - Power BI Desktop report with Star Schema data modeling

---

## Tech Stack and Tools
- Python: Pandas, NumPy, Plotly, Streamlit, Pillow
- SQL: Advanced CTEs, Window Functions (DENSE_RANK, LAG, NTILE), Relational Constraints
- Power BI: Star Schema data modeling, DAX measures

## Key Performance Indicators (KPIs)

| Metric | Measured Value | Operational Insight |
|---|---|---|

| Average Order Value (AOV) | INR 994.48 | Baseline basket size across customer cohorts |
| On-Time Delivery SLA Rate | 69.40% | Operational bottleneck with 30.6% delayed deliveries |
| Inventory Damage Rate | 3.8% | Tracked across inbound damaged inventory records |
| Blended Margin | 27.78% | Baseline product catalog profitability |
| Campaign ROAS | 1.97x | Return on advertising spend across marketing channels |

---

## Analytical Findings
- Delivery SLA and Hub Radii: Orders with transit distance exceeding 4.5 km showed a 2.3x surge in delivery SLA breaches.
- Pareto Principle in Demand: Top categories (Dairy, Fresh Produce, Beverages) account for 74.2% of total order volume.
- Customer Retention: RFM segmentation revealed that 22% of customer lifetime value is generated by the top 8% VIP tier.

## How to Run Locally

1. Install Dependencies:
   pip install -r requirements.txt

2. Run Automated ETL:
   python process_blinkit_data.py

3. Run Interactive Web Dashboard:
   streamlit run app.py
